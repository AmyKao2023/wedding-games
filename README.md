# 嘉宏 & 曼婷 · 婚禮小遊戲

粉色婚禮風格的兩個獨立小遊戲，純 HTML、CSS、JavaScript，不需安裝套件或建置。

## 檔案

- `index.html`：遊戲選擇入口。
- `bingo/index.html`：幸福賓果，預設 1–90，不重複抽號，支援全螢幕、空白鍵及進度保存。
- `lucky-guests/index.html`：幸福點名，先抽桌號，再按一次抽座位號碼（固定 1–10），同一組桌號／座位不重複抽出。

## 使用方式

下載儲存庫 ZIP 並解壓縮，用瀏覽器開啟各遊戲資料夾中的 `index.html` 即可。入口頁以相對連結選擇遊戲。離線亦可操作；幸福點名的線上字型若無法載入，會使用備用字型。

## 賓果卡與連線

已依提供的兩張照片輸入 10 張 3×3 卡片，數字合計涵蓋 1–90，各一次。每張卡的橫、直、斜三格都算連線。新連線完成時顯示「恭喜賓果」、撒花瓣，並標示卡片與連線號碼。

請婚禮前透過「查看／編輯賓果卡」核對卡面；自動判斷只涵蓋已輸入的卡片，其他卡片需自行新增。照片卡片編號依網站顯示順序，並非實體印刷編號。

## 保存與重設

進度與卡片設定保存在目前瀏覽器的本機儲存空間，不會跨裝置同步。使用「重新開始這一局」清除抽選進度。

此儲存庫目前為私人；上傳程式碼不代表已開啟網站託管。
